KKKhane 2.0 Deployment & Separation Guide

Step-by-step procedure to completely disconnect from the old Vercel project, Supabase DB, and domain.

1 Disconnect Old GitHub Repository

Remove the connection to the original git remote and point the codebase to your own GitHub repository:

cd "/Users/aayushjoshi/kkkhane 2.0"

# Remove original remote reference
git remote remove origin

# Link your new GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/YOUR_NEW_REPO_NAME.git

# Set main branch and push code
git branch -M main
git push -u origin main
2 Set Up Your Own Supabase Database

1. Log in to supabase.com and click New Project.

2. Run migrations locally to build your complete database schema on the new instance:

npx supabase link --project-ref YOUR_NEW_PROJECT_REF
npm run db:push

3. Retrieve your API credentials from Project Settings → API:

  • NEXT_PUBLIC_SUPABASE_URL
  • NEXT_PUBLIC_SUPABASE_ANON_KEY
  • SUPABASE_SERVICE_ROLE_KEY
3 Deploy to Your Vercel Account

1. Log into your Vercel account and click Add New... → Project.

2. Import your new GitHub repository created in Step 1.

3. Configure the following environment variables in Vercel settings:

Environment Variable Description / Action
NEXT_PUBLIC_SUPABASE_URL Your new Supabase Project URL
NEXT_PUBLIC_SUPABASE_ANON_KEY Your new Supabase Anon Public Key
SUPABASE_SERVICE_ROLE_KEY Your new Supabase Service Role Secret Key
NEXT_PUBLIC_APP_URL https://your-domain.com (or Vercel URL)
CRON_SECRET Random secret string (e.g. openssl rand -hex 32)
REVALIDATE_SECRET Random secret string
SRMS_API_KEY Random secret string
4 Configure Custom Domain DNS

1. In your Vercel project, go to Settings → Domains and enter your domain name.

2. Configure DNS records at your domain provider (Cloudflare, GoDaddy, Namecheap, etc.):

Type:  A      | Name: @   | Value: 76.76.21.21
Type:  CNAME  | Name: www | Value: cname.vercel-dns.com
5 Local Development Environment (.env.local)

Update your local environment file at /Users/aayushjoshi/kkkhane 2.0/.env.local:

# --- Supabase (Your New Instance) ---
NEXT_PUBLIC_SUPABASE_URL=https://your-new-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_new_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_new_service_role_key

# --- Local Host ---
NEXT_PUBLIC_APP_URL=http://localhost:3000

# --- Flags ---
SHOW_DEMO_ACCOUNTS=true
